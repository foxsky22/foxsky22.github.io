# Jayce Sardo Portfolio V2.1

Extract the ZIP and open index.html in a browser. Keep styles.css, script.js, and the assets folder alongside it.

The portfolio opens in its original clickable layout unless you previously enabled Scroll view. Use the switch at the bottom of the portfolio panel to change views. In Scroll view, the arrow returns to the top of the page on phones and to the top of the portfolio panel on desktop. The Contact Me menu includes Email, WhatsApp, and LinkedIn.

For GitHub Pages, upload the extracted contents to the folder configured as the publishing source. The profile currently uses the initials placeholder.
